How admins grant access

Roles are Django Groups. An authorized user administrator creates a group such as loan_users under Admin → Authentication and Authorization → Groups, and assigns it to users under Users.

In Tool setup, discover the loan tool, select that group, enable the tool, check the model and save. Tool activation and required approvals still apply. Branch/data permissions must also be enforced by the backend.

History reviewers need Staff status and the “Can view agent run log” permission. Tool setup administrators additionally need “Can add agent tool”, “Can change agent tool” and “Can change system setting”. Ordinary loan users do not need Staff status.

The existing role resolver treats users without groups as staff. Use a dedicated group such as loan_users for restricted loan access. The admin role is privileged and should not be assigned to ordinary users.
