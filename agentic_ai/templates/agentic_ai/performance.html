What is measured?

These are application-side MCP execution timings. They exclude browser/network transfer, HTTP worker queueing, final log persistence, optional follow-up Bangla summaries and WhatsApp sharing. Cached HTTP replays reuse the original attempt and do not create a new timing trace. Local legacy query paths remain unmeasured.

The backend stage includes gateway transport, ContextForge, NiFi and database execution together. Use the request ID and backend logs to investigate further. Permission checks, approvals and scope verification remain enabled.
