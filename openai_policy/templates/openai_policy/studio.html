n8n / Automation REST API

n8n can call exactly the same workflow with HTTP Request nodes. Send X-Admin-Token when ADMIN_TOKEN is configured. FastAPI also exposes interactive schemas at /docs and /openapi.json.

POST
/policy-ai/api/admin/preprocess
Multipart upload; returns job_id immediately.
GET
/policy-ai/api/admin/preprocess/{job_id}
Poll job status: queued → extracting → normalizing → ready/review_required.
GET
/policy-ai/api/admin/preprocess/{job_id}/artifact/unicode
Read normalized Unicode text. Replace unicode with atomic or markdown.
POST
/policy-ai/api/admin/preprocess/{job_id}/approve
JSON: {"approved":true,"note":"reviewed"}.
POST
/policy-ai/api/admin/effective/build
JSON with approved job_ids; creates one consolidated effective Markdown.
GET
/policy-ai/api/admin/effective/{build_id}/artifact/markdown
Read the final effective RAG document before publication.
POST
/policy-ai/api/admin/effective/{build_id}/upsert
Publish final Markdown to OPENAI_VECTOR_STORE_ID.
POST
/policy-ai/api/admin/search-test
Multipart field query; verifies live vector retrieval.
GET
/policy-ai/api/admin/files
List live vector-store files and metadata.
DELETE
/policy-ai/api/admin/files/{file_id}
Detach/delete a live vector-store file.
